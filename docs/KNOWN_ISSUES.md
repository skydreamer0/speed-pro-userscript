# 已知問題：1.1.0

以下由原碼檢閱發現；除明列為靜態檢查外，尚未在瀏覽器重現。此匯入版本未修改功能。

## 非 YouTube 設定面板初始化錯誤

`ensurePanel()` 在非 YouTube 網站移除 `[data-action="reset-channel"]`，隨後卻對同一個查詢結果直接呼叫 `.addEventListener()`。依控制流程，該結果為 `null`，首次初始化會拋出 TypeError，並中斷後面的「重設設定」與點擊面板外關閉事件綁定。第二次開啟可能顯示已建立的面板，但不會補回遺漏的事件綁定。

修復方向：僅在元素存在時綁定事件，並補上非 YouTube 初始化回歸測試。此版本先保留原始碼供追溯。

## SponsorBlock 限制

- 影片 ID 只讀取 `v` query；一般 Shorts／embed 路徑沒有對應 ID 解析。
- 回應只驗證 `segment` 陣列長度，未完整檢查數值有限性、順序、片長邊界；伺服器回傳異常可能造成不合理跳轉。
- 「返回」按鈕只回到先前位置，沒有持續略過該區段的排除清單；播放後仍可能再次跳段。
- 關閉功能或導航時，未在每條路徑使正在進行的舊請求失效；跨影片快速導航的回應競態需要測試。

## 設定與鍵盤

- `rememberGlobal` 不是停止儲存的總開關；其他變更路徑仍呼叫 `saveSettings()`，UI 也沒有這個切換項目。
- `localStorage` 寫入未捕捉例外；被封鎖、額度不足或資料格式不符可能中斷流程。
- 重設設定只重新繪製部分標籤，沒有同步所有既有數字／checkbox 控制項，也未明確重設鎖定與當前播放速度。
- 未註冊失去焦點／頁面隱藏時停止按住加速的處理，可能漏接放鍵事件。
- `keyup` 對 Backquote 的處理未檢查輸入焦點或先前是否真的開始加速，可能在輸入情境中恢復基準速度。
- `Tab` 在加速或鎖定時會被攔截，可能妨礙鍵盤焦點導覽；需要專門的無障礙測試。

## 播放與介面

- 0.25×–16× 是程式設定範圍，不是所有平台支援的保證。
- 廣告輔助依賴 YouTube DOM class 與略過按鈕選擇器，網站變動後可能失效。靜音恢復的是 `muted` 狀態，不是音量數值。
- PiP、全螢幕與截圖取決於 API 與權限。跨來源 canvas 可能無法匯出 PNG。
- 多影片可見、切換 Reel、廣告途中換片、SPA 導航與低頻 watchdog 的交互行為未驗收。
